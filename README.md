# pixdeo/homebrew-tap

Homebrew tap for [editxr](https://github.com/pixdeo/editxr) — a minimalist Markdown editor for the terminal.

## Install

```sh
brew install pixdeo/tap/editxr
```

This pulls the Developer ID-signed, notarised universal (arm64 + x86_64) binary
from the [editxr releases](https://github.com/pixdeo/editxr/releases).

## Update

```sh
brew update && brew upgrade editxr
```
